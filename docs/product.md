# Quiz Monorepo - 产品文档

## 产品定位

Quiz App 是一个面向开发者的知识问答平台，帮助用户通过答题巩固 JavaScript、数据库、网络协议、算法等技术知识。

**两端架构**：

| 端     | 应用                       | 目标用户               |
| ------ | -------------------------- | ---------------------- |
| 用户端 | `quiz-app`（端口 10000）   | 答题用户               |
| 管理端 | `quiz-admin`（端口 10050） | 内容管理员、超级管理员 |

---

## 用户端功能（quiz-app）

### 已实现

**答题核心流程**：

1. 页面加载自动获取一道随机题目
2. 展示题干 + 所有选项（答题前不显示解析）
3. 用户点击选项即提交，不可更改
4. 后端返回判定结果 + 解析
5. 答对：绿色高亮 + 展示所有选项解析 + 1 秒后自动跳转
6. 答错：红色高亮错误选项 + 绿色高亮正确选项 + 展示解析 + 手动点击下一题

**UI 特性**：

- 暗色/亮色主题切换（系统主题检测 + 手动切换）
- 响应式布局（移动端适配）
- 渐变标题 + 泛光效果

### 计划中

**用户身份（游客模式 + 可选绑定）**：

- 游客直接答题，无需登录，答题功能完整（后端 OptionalUserJwtGuard 已支持）
- Header 右侧显示「登录」按钮，点击弹出**对话框**（非独立页面，不中断答题流程）
- 对话框内包含登录/注册两个 Tab，使用共享 UI 库的 BaseDialog + BaseInput 组件
- 登录后将游客历史同步到服务器（后端 AnswerAttempt 已支持 userId 关联）

**用户菜单（登录后）**：

- Header 右侧「登录」按钮替换为用户头像/图标 + 用户名
- 点击展开下拉菜单：做题历史 / 分类偏好 / 退出登录

**做题历史（侧边抽屉面板）**：

- 从右侧滑出，不离开答题页面
- 筛选：全部 / 答对 / 答错
- 卡片列表：题干(截断) + 正误徽标 + 选择的选项 + 相对时间
- 无限滚动加载（触底自动加载下一页）
- 未登录时显示提示「登录后查看答题记录」

**偏好分类（Miller Columns 分栏选择器）**：

- 答题页显示「选择分类」按钮 + 已选分类标签
- 点击弹出对话框，采用 macOS Finder 风格的分栏浏览器：
  - 左列维度 → 右列逐级展开分类，点击文字展开、点击指示器选中
  - 三态选中：全选 / 半选（部分子级选中）/ 未选中
  - 选中父级自动包含所有子级
- 顶部搜索框跨层级过滤 + 已选摘要可逐个移除
- 已登录 → 偏好同步到服务器；游客 → 保存在 localStorage
- **叶子节点约束**：题目只能挂到叶子分类；每个非叶子节点自带「通识」子节点，收纳不适合细分的题目。通识节点显示名拼接父名（如「前端通识」），创建/删除子分类时自动维护（含题目关联和用户偏好的迁移）

**实时通知（WebSocket）**：

- 管理员发布 app 更新时，客户端收到事件后刷新页面
- 支持公告推送（弹窗提示）

## 管理端功能（quiz-admin）

### 已实现

| 模块       | 功能                                                                           |
| ---------- | ------------------------------------------------------------------------------ |
| 认证       | JWT 登录、7 天有效期、刷新不丢失                                               |
| 权限系统   | RBAC（菜单权限 + API 权限）、动态路由、超级管理员通配符                        |
| 管理员管理 | CRUD、角色分配、保护规则（超管不可删除/改权限）                                |
| 角色管理   | 自定义角色、菜单/API 权限配置                                                  |
| 题目管理   | 列表/搜索/筛选、新建/编辑/软删除、动态选项、分类关联（仅叶子节点）             |
| 分类管理   | 多维度 + 无限层级树形、「通识」节点自动生命周期管理（不可删除/改名，灰色区分） |
| 用户管理   | 列表/搜索/分页、用户详情、做题历史、偏好分类、状态切换                         |
| 布局       | Header + Sidebar 折叠 + Tab 历史 + keep-alive + 深色模式                       |

### 计划中

**系统日志**：

- 自动记录所有增删改 API 操作（请求参数、响应、耗时、操作者）
- 记录管理员登录日志（含失败记录）
- 可筛选查看（按类型/操作者/时间/成功失败）

**客户端管理**：

- 实时查看在线 quiz-app 客户端（用户名或游客 + IP + 当前页面）
- 广播事件（强制刷新 / 公告通知）
